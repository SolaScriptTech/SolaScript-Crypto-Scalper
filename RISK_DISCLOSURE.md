# Risk Disclosure

SolaScript versions may transmit live cryptocurrency orders. Automated scalping can generate rapid losses, excessive fees, unexpected exposure, or repeated orders before an operator can intervene.

Risks include software defects, exchange outages, API changes, stale market data, rate limiting, latency, slippage, partial fills, strategy overfitting, corrupted local state, and incorrect assumptions about liquidity or fees.

No backtest, paper result, or historical observation guarantees future performance. Use only capital you can afford to lose.

Use a dedicated API key with minimum permissions. Never enable withdrawals. Test a paper-trading adaptation before using live credentials.
